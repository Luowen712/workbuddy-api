# WorkBuddy Operations Console

Approved direction: professional operations workbench, single local administrator.
Palette: neutral white / charcoal surfaces; teal actions; amber warnings; red failures; blue request-series and teal success-series. No gradients or emoji.
Typography: local Segoe UI, Microsoft YaHei, system sans; 14px body, 24px page titles, 30px metrics, zero letter spacing. Monospace IDs.
Layout: 224px sidebar, 56px header, 24px desktop content; unframed sections separated by rules. Metrics are compact strips. Detail drawers on right. Radius 6px.
Mobile: drawer navigation, single-column sections, field labels visible, request/account records stacked. Minimum controls 36px; keyboard focus and reduced motion supported.
Theme: system by default, persisted light/dark override. Icons: Lucide. Visual asset: upstream WorkBuddy product mark, stored locally.
Charts: real persisted telemetry only; empty state until requests arrive. Unknown, zero, disabled and unavailable remain distinct.
Preserve existing authentication, read-only/dangerous operation gates, credential and config ownership.
